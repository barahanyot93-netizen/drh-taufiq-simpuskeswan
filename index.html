Pengaturan Laporan

Backup Data

Unduh seluruh data aplikasi (Pemilik, Hewan, Pelayanan, Vaksinasi, Stok Obat) sebagai satu file Excel untuk cadangan/arsip. Simpan file ini di tempat aman (Google Drive/laptop).

Perbaiki Kepemilikan Data Lama

Data Pelayanan & Vaksinasi yang dientri sebelum pembaruan keamanan belum punya penanda pembuat. Alat ini mencocokkan otomatis berdasarkan nama petugas yang tercatat dengan profil di Data Petugas (hanya jika namanya cocok persis dan unik). Yang tidak bisa dicocokkan dengan pasti akan dilaporkan, tidak dipaksakan.

Tetapkan Pembuat Data Peternak/Ternak Lama

Data Peternak & Ternak tidak pernah mencatat nama petugas, jadi tidak bisa dicocokkan otomatis seperti Pelayanan/Vaksinasi. Tombol di bawah menandai SEMUA data yang belum punya pembuat ke satu petugas sekaligus. Kalau pembuatnya campuran beberapa petugas, lebih baik pakai cara pilih manual: buka halaman Data Pemilik / Data Hewan, centang kotak di baris yang belum ada pembuatnya (muncul khusus untuk Admin), lalu pilih petugas tujuan dan klik "Terapkan ke Terpilih" — bisa diulang per kelompok data untuk tiap petugas.

Gabungkan Akun Duplikat

Pakai ini kalau satu petugas ternyata punya dua akun/UID berbeda (misalnya pernah daftar ulang), sehingga data lamanya terpisah di dua identitas. Semua data Peternak, Ternak, Pelayanan & Vaksinasi milik akun lama akan dipindah kepemilikannya ke akun yang benar.

Kalau akun lama sudah terlanjur dihapus dari Data Petugas, UID-nya masih bisa diambil dari data lama: buka Firebase Console → Firestore → koleksi pelayanan atau vaksinasi → buka salah satu dokumen milik petugas tersebut → salin nilai field createdBy, tempel di sini.
